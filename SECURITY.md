# Security Policy

## Supported Versions

The following table lists the versions of PySpectrometer that are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | Yes                |
| 3.1.x   | Limited            |
| < 3.1   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository, please report it privately:

1. Do not report security vulnerabilities through public GitHub issues.
2. Submit vulnerability details through GitHub Security Advisories or contact the repository maintainers directly.
3. Include detailed steps to reproduce the vulnerability, including any malicious file payloads or memory exploitation vectors.

Maintainers will respond promptly to acknowledge the report and coordinate disclosure following verification and remediation.
